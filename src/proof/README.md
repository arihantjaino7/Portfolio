# Proof artifacts

Raw output, unedited. Drop a `.txt` file here and reference it from a case
study's `proof.file` — the path is relative to this directory.

```
src/proof/arc/tests.txt          ← referenced by src/content/work/arc.mdx
src/proof/sentinels/autofix.txt  ← referenced by src/content/work/sentinelsai.mdx
```

Until the file exists, `/work/<slug>` renders a labelled frame naming the exact
path it is waiting for. The headline claim in `proof.summary` renders either way.

Paste real output. A fabricated test run is worse than an empty slot — this
section is the only part of the site a reader cannot get from a résumé.
